# 🚀 Welcome

Welcome to the **Cyber Security & Penetration Testing** course.

This repository contains a **90-Day structured learning roadmap** covering:

- Cyber Security Fundamentals
- Networking
- Linux
- Windows Security
- Web Application Security
- Penetration Testing
- Ethical Hacking
- Active Directory
- Cloud Security
- Wireless Security
- Malware Analysis
- Digital Forensics
- CTF Practice
- Bug Bounty
- Reporting
- Career Guidance

Each lesson is written in Markdown for easy reading on GitHub.

---

# ⚠️ Disclaimer

> **This course is strictly for educational, research, and authorized security testing purposes only.**

The techniques demonstrated in this repository must **ONLY** be used on:

- Systems you own
- Lab environments
- Virtual Machines
- Capture The Flag (CTF) challenges
- Targets with explicit written authorization

Unauthorized access, exploitation, scanning, or attacks against systems without permission are illegal and may violate local, national, and international laws.

The author, contributors, and repository maintainers are **NOT responsible** for any misuse of the information contained in this repository.

By using this repository, you agree to use the knowledge responsibly and ethically.

# 🎯 Course Goal

Become capable of performing professional penetration testing and security assessments while understanding how to protect modern systems.
